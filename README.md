# FuzzCraft 4

A modpack for a casual friend group built around two pillars: factory automation and dimension exploration.

**Minecraft:** 1.21.1 — **Loader:** NeoForge 21.1.233

---

## Player Setup

Download `packwiz-installer-bootstrap.jar` once and add the following as a pre-launch command in ATLauncher or Prism Launcher:

```
"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://fuzzymelon94.github.io/FuzzCraft-4/pack.toml
```

The launcher will fetch and sync the latest pack automatically on every launch.

**Recommended RAM:** 4–6 GB
